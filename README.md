# gediao-tutorial · 格调使用教程

《亲密解剖与动作科学指南：3 分钟全幅动态透视图谱》—— 单文件 HTML 程序化渲染科普视频。

## 这是什么

整支视频由一个 HTML 文件驱动：Canvas 2D + SVG 逐帧程序化动画，无任何外部素材依赖，双击即可在浏览器播放。

- 分辨率：1920×1080 @ 60fps
- 时长：180s（`window.DURATION`）
- 形态：横版成品已渲染为 mp4；竖版成品见 Releases
- 内置文献出处弹窗（ref-modal），列出本片引用的科学文献与临床研究

## 使用

| 操作 | 方法 |
|---|---|
| 播放预览 | 浏览器直接打开 `index.html` |
| 录制模式 | 打开 `index.html?record=1` —— 固定 1920×1080 视口、隐藏播放控制条，配合录屏逐帧采集 |
| 在线观看 | 启用 GitHub Pages 后访问仓库 Pages 地址 |

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 视频源码（动画、时间轴、章节标题全部内嵌） |
| `intimacy_science_guide_1080p60.mp4` | 横版成品（约 65MB） |
| 竖版 1080p60 | 体积超 GitHub 单文件限制，挂在 [Releases](../../releases) |
